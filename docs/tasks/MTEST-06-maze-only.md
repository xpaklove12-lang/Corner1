# [개발중] 테스트 씬에서 미로만 하기

대상: MTEST-06, MTEST-07 · 영역: [눈 미로 테스트 씬](../specs/maze-test.md)

> 작업 문서다. 진행 상태와 승인은 여기서 관리하고, 완료된 기능은 영역 스펙에 옮긴다. 지금 게임이 어떻게 동작하는지는 영역 스펙이 기준이다.

사용자가 "테스트 씬에서는 컷신 같은 건 싹 건너뛰고 미로만 있게" 바로 작업하라고 요청해서 `[개발중]`으로 시작했다.

## 무엇을 만드나

### 파편 숨기기 (MTEST-06)

테스트 씬에서 기억 파편을 모두 숨겨, 회상 장면이나 파편 글 없이 미로만 한다.

- 미로에 파편이 보이지 않고, 지나가도 아무것도 줍지 않는다. 회상 장면 그림과 회상 방이 나오지 않는다.
- 동공 한가운데의 가장 반짝이는 파편(탈출 지점)은 그대로 있다.
- Inspector에서 고른다. 기본 켬. Play 중 끄면 숨겼던 파편이 다시 나타난다.
- 시작 독백과 첫 손님 컷신은 원래(MTEST-01) 꺼져 있다.

### 동공을 미로 구멍에 맞추기 (MTEST-07)

테스트 씬에서 동공이 늘 미로 안쪽 원과 같은 크기다.

- 동공이 손님의 동공 크기 값으로 혼자 커지거나 작아지지 않는다. 미로 안쪽 원 크기를 바꾸면 동공도 같이 바뀐다.
- 움찔 수축과 떨림 같은 연출은 그대로 보인다.
- 동공 Inspector에서 맞출 미로를 비우면 예전처럼 동공 크기 값을 따른다. 본 게임 씬은 비어 있어 이전과 같다.

## 확인 방법

- `MazeTest` 씬을 Play하면 독백, 컷신 없이 바로 미로가 뜨고 파편 마름모가 보이지 않는다.
- 미로를 돌아다녀도 회상이나 파편 글이 나오지 않는다.
- 동공 한가운데에 닿으면 탈출 안내가 나온다.
- Play 중 파편 숨기기를 끄면 파편이 다시 보이고, 닿으면 회상이 나온다.
- 동공 가장자리가 미로 가장 안쪽 원과 맞고, 미로를 오래 돌아다녀도 동공 크기가 바뀌지 않는다.
- 본 게임 씬은 이전과 똑같이 동작한다.

## 범위 밖

- 파편, 회상, 상처 무늬 기능 자체는 바꾸지 않는다.
- 본 게임 씬에서는 파편을 숨기지 않는다.

## 어떻게 만드나

- `MazeTestStarter`에 `_hideFragments`를 두고, 매 프레임 `ApplyConditions`에서 `ApplyFragmentVisibility`를 부른다. 켜져 있으면 디렉터의 지금 파편(`EyeMazeDirector.Fragments`, 켜진 것만)을 끄고 목록에 모은다. 꺼지면 모은 파편만 다시 켠다.
- 꺼진 파편은 디렉터의 파편 줍기 검사에 걸리지 않아 읽기와 회상이 일어나지 않는다. 디렉터는 바꾸지 않는다.
- 상처 단계 수는 상담의 전체 파편 수로 정해지므로 숨겨도 `[ ]` 단계 옮기기는 그대로 된다.
- 동공 맞춤(MTEST-07): `Pupil`에 `_fitMaze`를 두어, 연결되면 `TargetRadius`가 dilation 대신 `FitRadius`(미로 안쪽 반지름을 월드 크기로 바꾼 뒤 동공 기준으로 되돌린 값)를 쓴다. 테스트 씬의 동공에만 미로를 연결했다. 대화가 없는 테스트 씬은 dilation이 처음값 0.2에 머물러 동공 반지름이 약 0.4로, 미로 안쪽 원 0.9와 크게 어긋났다. 사용자 요청으로 동공이 혼자 커지는 연출을 빼고 미로 크기를 따르게 했다. 문 통과에 쓰는 dilation 값 자체는 바꾸지 않는다.

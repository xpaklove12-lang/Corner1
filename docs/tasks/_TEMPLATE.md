# [제안] 작업 이름

대상: XXX-03 · 영역: [영역 이름](../specs/영역-이름.md)

> 작업 문서다. 진행 상태와 승인은 여기서 관리하고, 완료된 기능은 영역 스펙에 옮긴다. 지금 게임이 어떻게 동작하는지는 영역 스펙이 기준이다.

## 무엇을 만드나

비개발자가 읽고 승인하는 부분이다. 쉬운 말로 쓰고 코드 이름은 쓰지 않는다.

### 단서를 닫을 때 (XXX-03)

단서 말풍선을 닫을 때는 눈을 깜빡이지 않는다.

- 다른 층의 길만 바뀐다.

## 확인 방법

- 말풍선을 닫아도 눈꺼풀이 내려오지 않는다.

## 범위 밖

- 말풍선을 닫을 때의 벽 재생성은 그대로 둔다.

## 어떻게 만드나

승인 뒤 개발자와 에이전트가 쓴다. 고칠 곳, 구조, 고른 방법과 버린 방법을 쓴다.

## 할 일

## 결과

완료할 때 쓴다. 확인한 것, 확인하지 못한 것, 남은 것.

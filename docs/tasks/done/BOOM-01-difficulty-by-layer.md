# [완료] 안쪽으로 갈수록 폭발 난이도가 오르게

대상: BOOM-01 · 영역: [폭발 미로](../../specs/maze-boom.md)

> 작업 문서다. 진행 상태와 승인은 여기서 관리하고, 완료된 기능은 영역 스펙에 옮긴다. 지금 게임이 어떻게 동작하는지는 영역 스펙이 기준이다.

사용자가 "지금 폭발 난이도가 너무 빡세다. 해금해서 안쪽 세이브 포인트일 때 난이도가 점진적으로 올라가게" 해 달라고 했다. 단계 기준은 연 문 수, 기본값은 제안대로 하기로 승인했다.

## 무엇을 만드나

### 터지는 칸 무늬 (BOOM-01)

폭발 난이도가 단계로 나뉘고, 문을 열어 안쪽으로 들어갈수록 단계가 오른다.

- 처음(외각)은 1단계, 외각 조각을 먹어 내각 문을 열면 2단계다. 층이 늘면 단계도 그만큼 늘어난다.
- 단계마다 두 가지를 정한다.
  - 빠르기: 무늬가 도는 빠르기 배율. 낮을수록 경고가 길고 터지는 간격이 넓다.
  - 터지는 칸 비율: 무늬가 고른 칸 중 실제로 터지는 칸의 비율. 낮을수록 피할 칸이 많다. 빠지는 칸은 반복마다 고르게 섞여, 같은 칸만 늘 비지 않는다.
- 기본값: 1단계 빠르기 0.6배·칸 50%, 2단계 빠르기 0.8배·칸 75%. 지금의 난이도(1배·100%)보다 모두 쉽다. 단계 값은 프리팹에서 고친다.
- 단계가 오를 때 "폭발이 거세진다." 안내가 뜬다.
- 바퀴마다 조금씩 빨라지는 것(최대 1.6배)은 단계 빠르기에 곱해진다. 휩쓸려 돌아가도 단계는 내려가지 않고, R로 다시 하면 1단계부터다.

## 확인 방법

- `MazeTest`를 Play하면 외각에서는 지금보다 폭발이 느리고 드문드문하다.
- 외각 조각을 먹어 내각 문이 열리면 "폭발이 거세진다."가 뜨고, 폭발이 조금 더 빠르고 촘촘해진다.
- 휩쓸려도 단계가 유지되고, R로 다시 하면 1단계로 돌아간다.

## 범위 밖

- 무늬 순서표(체크, 대각선, 흩뿌림)와 경고·폭발 색은 바꾸지 않는다.
- 층, 문, 조각, 안전지대는 바꾸지 않는다.

## 어떻게 만드나

- 단계 설정 묶음 `BoomStage`(빠르기, 터지는 칸 비율)를 새로 두고, `MazeBoomField`에 단계 목록과 단계 오름 안내 문구를 둔다.
- 지금 단계는 사각 미로의 연 문 수(`BoomSquareMaze.OpenedGateCount`)로 정하고 목록 끝에서 멈춘다. `TakeShard`가 조각을 먹어 단계가 오르면 문 열림 안내 아래에 단계 오름 안내를 붙인다.
- `Advance`는 바퀴 배속에 단계 빠르기를 곱한다. `EvaluateCells`는 무늬가 고른 칸마다 칸, 반복, 무늬 번호로 뽑은 값이 단계 비율보다 크면 건너뛴다.
- `UI.csv`에 `msg.boom_stage_up`을 더한다.

# [완료] 층 경계 벽과 문도 1픽셀로

대상: BOOM-09, BOOM-10 · 영역: [폭발 미로](../../specs/maze-boom.md)

> 작업 문서다. 진행 상태와 승인은 여기서 관리하고, 완료된 기능은 영역 스펙에 옮긴다. 지금 게임이 어떻게 동작하는지는 영역 스펙이 기준이다.

사용자가 "벽이 여전히 두껍다"고 해서 `[개발중]`으로 시작했다. 실제 Game 창을 캡처해 보니 보통 벽은 1픽셀인데, 층 경계 벽과 문이 2픽셀이라 6픽셀 칸에 비해 두드러지게 두꺼웠다.

## 무엇을 만드나

### 벽 굵기 (BOOM-09, BOOM-10)

- 보통 벽, 층 경계 벽, 문 모두 화면에서 1픽셀로 같은 굵기다.
- 층 경계 벽은 굵기로 구분되지 않는다. 문은 노란색으로 구분된다.
- 층 경계 벽 굵기 배율은 프리팹에 남겨 두어 다시 키울 수 있다.

## 확인 방법

- `MazeTest`를 Play하고 Game 창을 캡처하면 모든 벽과 문이 1픽셀이다.

## 범위 밖

- 벽 색, 격자선, 층과 문의 동작은 바꾸지 않는다.

## 어떻게 만드나

- `MazeBoom.prefab`과 `BoomSquareMaze._layerWallWidthScale` 기본값을 2에서 1로 바꾼다. 코드 동작은 바꾸지 않는다.

## 결과

- 바꾼 문서: `docs/specs/maze-boom.md`의 BOOM-09(모든 벽 1픽셀), BOOM-10(층 경계 굵기는 보통 벽과 같음).
- 코드: `BoomSquareMaze._layerWallWidthScale` 기본값과 툴팁, `MazeBoom.prefab`의 같은 값을 1로.
- 확인한 것: 컴파일, Play 중 배율 값 1. Game 창을 캡처해 모든 벽이 가늘어진 것을 봤다. 벽마다 화면 위치를 구해 픽셀 두께를 셌더니 보통 벽 56개 중 55개, 층 경계 벽 39개, 문 1개가 1픽셀이었다(나머지 1개는 다른 벽과 만나는 자리).
- 확인하지 못한 것: 1픽셀 문이 노란색만으로 충분히 눈에 띄는지는 사람이 봐야 한다. 캡처에서는 문이 작게 보였다.

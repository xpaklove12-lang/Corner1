# [완료] 격자선을 벽보다 덜 보이게

대상: BOOM-07 · 영역: [폭발 미로](../specs/maze-boom.md)

> 작업 문서다. 진행 상태와 승인은 여기서 관리하고, 완료된 기능은 영역 스펙에 옮긴다. 지금 게임이 어떻게 동작하는지는 영역 스펙이 기준이다.

사용자가 "격자선이 벽보다 덜 보여야 하는데 너무 잘 보인다, Unity로 확인하고 고쳐라"라고 지시해 `[개발중]`으로 시작했다.

## 무엇을 만드나

### 격자선 (BOOM-07)

격자선이 늘 벽보다 가늘고 흐리게 보여, 벽(길)이 먼저 눈에 들어오고 격자는 칸을 나누는 바탕으로만 보인다.

- 격자선은 화면에서 1픽셀 굵기다. 벽보다 굵어지지 않는다.
- 격자선은 어두운 반투명 회색이라 검은 홍채 위에서 겨우 보이고, 흰 벽보다 훨씬 어둡다.
- 화면 크기나 카메라 확대가 바뀌어도 1픽셀 아래로 가늘어져 사라지지 않는다.

## 확인 방법

- `MazeTest` 씬을 Play하고 Game 뷰를 보면 격자선이 흰 벽보다 가늘고 어둡다. 벽이 먼저 보이고 격자는 그 사이 칸 경계로만 보인다.
- 격자선이 끊기거나 사라진 곳이 없다.

## 범위 밖

- 벽 굵기나 색은 바꾸지 않는다.
- 칸 그림(경고, 폭발, 안전지대) 색은 바꾸지 않는다.

## 어떻게 만드나

- 원인: Play 중 값을 읽어 보니 격자선 굵기가 0.098(최소 2픽셀)인데 벽은 0.06(약 1.2픽셀)이라, 격자가 벽보다 두껍게 그려졌다. 화면은 480×270 렌더 텍스처를 Point 필터로 키우고, 선 재질은 `Sprites/Default`다(별도 셰이더 없음).
- 프리팹 `MazeBoom`의 `_gridMinPixels`를 1, `_gridWidth`를 0.03(1픽셀보다 작아 최소 픽셀이 정한다), `_gridColor`를 더 어둡고 투명한 회색으로 바꾼다. 코드 기본값도 같이 맞춘다.
- Unity Pipeline CLI(`unity command`)로 Play를 다시 시작해 런타임 굵기를 읽고 Game 뷰를 캡처해 벽과 비교한다.

## 결과

- 바꾼 문서: `docs/specs/maze-boom.md` BOOM-07(1픽셀, 벽보다 어둡게).
- 코드: `MazeBoom.prefab`의 `_gridColor`(회색 0.5, 투명도 0.22), `_gridWidth`(0.03), `_gridMinPixels`(1). `MazeBoomField`의 같은 기본값과 툴팁.
- 확인한 것: Unity Pipeline CLI로 Play를 다시 시작해 런타임 값을 읽었다. 격자선 굵기 0.0489(1픽셀), 색 회색 0.5·투명도 0.22, 벽 굵기 0.06, 흰색. 바꾸기 전에는 격자선이 0.0978(2픽셀)로 벽보다 두꺼웠다. Game 뷰를 바꾸기 전과 뒤로 캡처해 비교했고, 뒤에는 흰 벽이 먼저 보이고 격자는 칸 사이 어두운 선으로만 보였다.
- 확인하지 못한 것: 게임 창 크기를 여러 가지로 바꿔 본 것. 픽셀 카메라가 세로 270픽셀로 고정이라 창 크기와 상관없이 같은 굵기일 것으로 본다.

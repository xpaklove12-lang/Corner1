# [완료] 못 가는 바깥 칸은 그리지 않기

대상: BOOM-09, BOOM-07 · 영역: [폭발 미로](../../specs/maze-boom.md)

> 작업 문서다. 진행 상태와 승인은 여기서 관리하고, 완료된 기능은 영역 스펙에 옮긴다. 지금 게임이 어떻게 동작하는지는 영역 스펙이 기준이다.

사용자가 "못 가는 칸은 그리드 없도록 그냥 안 보여주도록" 해 달라고 직접 요청해 `[개발중]`으로 시작했다.

## 무엇을 만드나

### 원에 걸친 바깥 칸 (BOOM-09)

원에 걸쳐 들어갈 수 없는 바깥 칸은 아무것도 그리지 않는다.

- 미로 칸 바깥은 홍채 바탕만 보인다. 바깥 칸에는 격자선, 벽, 폭발이 없다.
- 들어갈 수 없는 것, 부딪히면 경계가 잠깐 빛나는 것(BOOM-08)은 그대로다.

### 격자선 (BOOM-07)

- 격자선은 미로 칸의 경계에만 그린다. 가장 바깥 미로 칸의 바깥 경계에도 격자선이 있어, 미로 가장자리가 옅은 회색 계단 모양으로 보인다.

## 확인 방법

- `MazeTest`를 Play하면 미로 칸 바깥(원에 걸친 칸 자리)에 격자선이 없고 홍채 바탕만 보인다.
- 바깥으로 누르면 여전히 튕기고 경계가 잠깐 빛난다.

## 범위 밖

- 미로 칸, 층, 문, 조각, 벽 굵기는 바꾸지 않는다.

## 어떻게 만드나

- `BoomSquareMaze.HasEdgeV`, `HasEdgeH`가 미로 칸에 닿는 경계만 그릴 경계로 본다. 그림 칸 판정(`IsDecorCell`, `IsGridCell`)과 원으로 선 자르기(`ClipSegment`)는 쓰이지 않게 되어 지운다. 미로 칸은 모두 원 안에 있으므로 자를 필요가 없다.

## 결과

- 바꾼 문서: `docs/specs/maze-boom.md`의 BOOM-09(바깥 칸은 그리지 않음), BOOM-07(격자선은 미로 칸 경계에만), 구성, 코드 단서.
- 코드: `BoomSquareMaze.HasEdgeV`, `HasEdgeH`가 미로 칸 경계만 본다. 쓰이지 않게 된 `IsDecorCell`, `IsGridCell`, `ClipSegment`를 지우고 `MazeBoomField.AddGridLine`의 자르기를 뺐다.
- 확인한 것: `unity recompile` 컴파일, 새 경고나 오류 없음. Game 뷰 캡처에서 미로 칸 바깥에 격자선이 없고 홍채 바탕만 보이며, 미로 가장자리는 옅은 회색 계단 모양이다. 시작 칸 (10, 1)에서 아래 바깥으로 밀면 튕기고 경계선이 빛나는 동안만 켜졌다가 1초 뒤 꺼졌다. 층 진행 자동 시험(닫힌 문 안내, 세 층 조각과 문, 동공 탈출)을 다시 통과했다.
- 확인하지 못한 것: 사람이 직접 키보드로 해 보는 손맛.

# [완료] 인트로 컷툰 소리

대상: SND-01, SND-02, SND-03, SND-04 · 영역: [사운드](../specs/sound.md), [인트로 컷툰](../specs/intro-cuttoon.md)

> 작업 문서다. 진행 상태와 승인은 여기서 관리하고, 완료된 기능은 영역 스펙에 옮긴다. 지금 게임이 어떻게 동작하는지는 영역 스펙이 기준이다.

## 무엇을 만드나

인트로 컷툰을 Play하면 칸마다 정해 둔 효과음과 환경음이 정해 둔 시점에 난다. 음악은 넣지 않는다. 칸을 넘기는 빠르기가 플레이어 손에 달려 박자와 맞지 않기 때문이다. 소리는 모두 위치가 없는 소리다(왼쪽·오른쪽 움직임은 음원 안에 넣어 두었다).

### 소리 재생 준비 (SND-01)

게임이 켜지면 저장소에 올린 소리 묶음(FMOD 뱅크)을 읽고, 소리를 듣는 자리를 하나만 둔다.

- FMOD Studio를 설치하지 않은 팀원 PC에서도 저장소를 받아 Play하면 소리가 난다.
- 효과음은 효과음 묶음으로, 환경음은 환경음 묶음으로 나가서 나중에 음량을 따로 조절할 수 있다.

### 칸별 소리 (SND-02)

시점은 그 칸이 열린 순간을 0초로 센다. 환경음은 끄라는 지시가 있을 때까지 반복되고, 효과음은 한 번 나고 스스로 끝난다.

| 칸 | 소리 | 시점 |
| --- | --- | --- |
| 1-1 도시 거리 | 멀리서 들리는 도시 소리가 켜진다 | 0초부터 0.45초 동안 커진다 |
| 1-2 그림자 | 새 떼가 날갯짓하며 스쳐 간다 | 0.5초 |
| 1-2 그림자 | 도시 소리가 먹먹하고 가늘어진다(9dB 작아지고 높은 소리가 깎인다) | 1.4초부터 2.2초 동안, 천천히 시작 |
| 1-3 올려다보기 | 새 소리 없음. 가늘어진 도시 소리만 이어진다 | - |
| 2-1 시민의 얼굴 | 운석이 다가오는 낮은 울림이 켜지고, 도시 소리가 사라진다 | 0.6초부터 2.0초 동안 |
| 2-2 운석 | 운석의 바람 소리가 점점 커진다 | 0.2초에 시작, 2.8초에 가장 크다 |
| 2-2 운석 | 낮은 울림이 세진다 | 0.2초부터 2.6초 동안, 천천히 시작 |
| 3-1 충돌 | 짧고 큰 충격음과 먹먹한 잔향. 같은 순간에 바람 소리와 낮은 울림을 줄이지 않고 바로 끊는다 | 0초 |
| 3-2 멸망과 출발 | 차갑고 얇은 우주의 울림이 켜진다. 불타는 소리는 넣지 않는다 | 0초부터 1.0초 동안 커진다 |
| 3-2 멸망과 출발 | 작은 우주선이 멀어지는 엔진 소리 | 0.4초 |
| 3-3 우주선 | 가까이서 듣는 엔진 분사음이 켜진다 | 0초부터 0.45초 동안 커진다 |
| 4-1 창 너머 지구 | 우주선 안의 낮은 기계 소리가 켜지고, 우주의 울림과 엔진 소리가 꺼진다 | 0초부터 0.8초 동안 |
| 4-2 우는 사람들 | 숨죽인 흐느낌 | 0.4초 |
| 4-3 주인공의 눈 | 떨리는 숨 한 번 | 0.5초 |
| 5-1 수면 캡슐 | 수면실의 차가운 기계 소리가 켜지고, 우주선 안 소리가 꺼진다 | 0초부터 0.8초 동안 |
| 5-2 뚜껑이 닫힘 | 유리 뚜껑이 모터로 닫히고 잠긴다 | 0.3초에 시작, 1.7초에 잠긴다 |
| 5-2 뚜껑이 닫힘 | 유리에 서리가 끼는 얇은 소리 | 1.7초 |
| 5-3 눈을 감다 | 눈이 세 번에 걸쳐 감길 때마다 수면실 소리가 3분의 1씩 멀어진다 | 0.6초, 1.5초, 2.4초 |

- 같은 환경음을 다시 켜라고 하면 겹쳐 틀지 않고 울리던 것을 그대로 둔다.
- 쪽을 넘겨도 켜져 있던 환경음은 끊기지 않고 이어진다.

### 넘김, 건너뛰기, 처음으로, 쪽 바로 가기 (SND-03)

칸 연출이 진행 중일 때 다음 칸 입력으로 연출을 끝 상태로 맞추면, 소리도 그 칸의 끝 상태로 맞춘다.

- 아직 나지 않은 효과음은 내지 않는다. 울리던 효과음은 짧게(0.15초) 줄여 끈다.
- 환경음이 켜지고 꺼지는 것과 먹먹해지는 정도는 짧게(0.2초) 그 칸의 끝 값으로 맞춘다.
- 3-1 충돌음만은 건너뛰어도 끝까지 울린다. 화면 연출이 다 끝난 뒤에도 울리고 있는 효과음은 다음 칸이 열려도 끄지 않는다.
- R로 처음부터 다시 열거나 숫자패드로 쪽을 옮기면, 울리던 소리를 짧게(0.1초) 줄여 끄고 그 쪽의 시작 상태를 만든다. 1쪽은 소리 없음, 2쪽은 먹먹해진 도시 소리, 3쪽은 소리 없음, 4쪽은 우주의 울림과 엔진 소리, 5쪽은 우주선 안 소리가 켜진 채로 시작한다.

### 마지막 암전 (SND-04)

마지막 칸 뒤 화면이 검게 덮이기 시작하면, 울리던 인트로 소리가 모두 화면이 덮이는 시간 동안 고르게 작아지고 암전이 끝나면 꺼진다.

## 확인 방법

- Intro 씬을 Play하고 1-1부터 5-3까지 연출이 끝난 뒤 한 칸씩 넘긴다. 칸마다 위 표의 소리가 그 시점에 나고, 표에 없는 소리와 음악이 나지 않는지 듣는다.
- 도시 소리가 1-2, 1-3과 2쪽으로 넘어가도 끊기지 않다가 2-1에서 사라지는지 듣는다.
- 2-2 연출 중에 넘겨 3-1로 가면 바람 소리와 울림이 끊기는 순간 충돌음이 나는지 듣는다. 3-1에서 바로 넘겨도 충돌음이 끝까지 울리는지 듣는다.
- 2-2에서 R을 누르면 1-1부터 소리가 다시 시작하고 앞의 소리가 남지 않는지, 숫자패드 2·4·5로 옮기면 위 시작 상태로 들리는지 듣는다.
- 5-3 뒤 암전에서 소리가 잦아들어 꺼지는지 듣는다.
- FMOD Studio가 없는 PC에서 같은 소리가 나는지는 팀원에게 부탁한다.
- Claude는 소리를 들을 수 없으므로 Play 중 각 소리의 재생 여부, 시점, 먹먹함 값을 기록으로 확인하고, 장면에 맞는지는 사용자가 듣고 정한다.

## 범위 밖

- 5-1의 금속 발소리는 음원이 정해질 때까지 넣지 않는다(보류).
- 음량 옵션, 대화 기록 창의 일시정지 소리, 배경음, 옛 오프닝의 초인종, Unity 기본 오디오 끄기, 빌드 배포 확인은 다음 작업으로 둔다.
- 컷툰의 화면 연출, 시간, 입력은 바꾸지 않는다.

## 어떻게 만드나

- 인트로 씬은 `IntroCuttoonGrayboxBuilder`가 통째로 다시 만들므로 씬과 빌더는 고치지 않는다. 소리 담당은 프리팹 `Assets/Sound/Resources/IntroCuttoonSound.prefab`에 두고, 씬이 열릴 때 `CuttoonPlayer`가 있으면 그 프리팹을 스스로 놓는다(사용자 결정). 빌더를 다시 돌려도 소리는 사라지지 않는다.
- 칸별 소리 표, 쪽 시작 상태, 건너뛰기·처음으로·암전에 쓰는 시간은 모두 프리팹의 Inspector 값이다.
- `CuttoonPlayer`에는 알림 네 개만 더한다. 칸이 열림, 연출을 끝 상태로 맞추기 직전, 처음으로·쪽 바로 가기, 암전 시작이다. 화면 연출, 시간, 입력은 그대로다.
- 칸이 끝나기 전에는 다음 칸이 열리지 않으므로, 건너뛰기는 마지막으로 연 칸의 소리에만 적용한다.
- 연출 틀(`CuttoonEffect`)을 쓰지 않는다. `Finish`가 진행 중이 아니면 바로 돌아가고, 쪽을 넘길 때 모든 연출이 되돌려져 여러 쪽에 걸치는 환경음을 다룰 수 없어서다.
- FMOD 이벤트 파라미터는 아래와 같다. 값은 FMOD Studio에서 고친다.
  - `City`의 `Hush`: 음량 0에서 -9dB, 필터 20kHz에서 1.5kHz
  - `MeteorRumble`의 `Intensity`: 음량 -2dB에서 +10dB, 한 옥타브 높인 같은 음원 층을 -80dB에서 -6dB로 섞음
  - `CryoBay`의 `Fade`: 음량 0에서 -18dB, 필터 20kHz에서 600Hz
- 5-3의 세 단계는 단계마다 0.3초 동안 3분의 1씩 바꾼다.

## 할 일

- [x] FMOD 파라미터 `Hush`, `Intensity`, `Fade`를 만들고 빌드한다.
- [x] `CuttoonPlayer`에 알림 네 개를 더한다.
- [x] 소리 담당 스크립트를 만든다(재생, 환경음 켜고 끄기, 파라미터 변화, 건너뛰기, 처음으로, 암전).
- [x] 프리팹을 만들고 칸별 소리 표와 쪽 시작 상태를 채운다. 듣는 자리(리스너)를 하나 둔다.
- [x] Play에서 칸마다 소리의 재생 여부와 시점, 파라미터 값을 기록으로 확인한다.
- [x] 확인 중 찾은 환경음 멈춤을 고친다. 환경음 6개에 FMOD 반복 구간을 넣는다.
- [x] 확인 중 찾은 2-2 건너뛰기 오류를 고친다. 다른 칸이 켠 환경음의 파라미터 변화도 끝 값으로 맞춘다.
- [x] 영역 스펙에 기능을 옮기고 이 문서를 완료로 바꾼다.

ID별 코드:

- SND-01: `Assets/Sound/Scripts/Runtime/IntroCuttoonSound.cs`의 `RegisterSceneHook`, `HandleSceneLoaded`, `Bind`. 프리팹 `Assets/Sound/Resources/IntroCuttoonSound.prefab`(소리 담당과 `StudioListener`).
- SND-02: 같은 파일의 `HandlePanelOpened`, `TickPending`, `Execute`, `TickVoices`, `TickRamps`. 자료 형식은 `IntroCuttoonSoundCue.cs`. FMOD 파라미터 `Hush`, `Intensity`, `Fade`와 환경음 6개의 반복 구간(`FMOD/Epic3Audio/Metadata/Event/`, `ParameterPreset/`).
- SND-03: `HandleFinishingOpened`, `HandleRestarting`.
- SND-04: `HandleBlackoutStarted`.
- 공통: `Assets/IntroCuttoon/Scripts/Runtime/CuttoonPlayer.cs`에 알림 네 개(`PanelOpened`, `FinishingOpened`, `Restarting`, `BlackoutStarted`)를 더했다. 화면 연출, 시간, 입력은 그대로다.

확인한 것(Play, 편집기 백그라운드 실행, 스크립트로 FMOD 인스턴스 상태를 읽음):

- 컴파일 오류 없음. 콘솔 오류 없음(경고는 소리와 상관없는 기존 `FieldNPC.cs` 하나).
- 씬이 열리면 소리 담당이 스스로 들어오고 듣는 자리가 하나다. 프리팹을 만들 때 열린 씬은 바뀌지 않았다.
- 1-1 도시 소리가 0.45초 동안 켜지고, 1-2에서 새 떼가 나고 `Hush`가 천천히 1까지 오른다. 53초가 지나도 도시 소리가 이어진다(반복 구간을 넣기 전에는 약 40초에 멈췄다).
- 2쪽 바로 가기에서 앞의 도시 소리는 바로 끊기고 `Hush` 1인 도시 소리가 새로 켜진 뒤 2-1에서 사라지며 울림이 켜진다.
- 2-2 연출 중 건너뛰면 바람 소리가 줄여 꺼지고 `Intensity`가 바로 1이 된다. 3-1에서 바람 소리와 울림이 끊기고 충돌음이 나며, 3-2가 열려도 충돌음이 이어진다.
- 3-2 우주의 울림과 우주선 소리, 3-3 엔진 소리, 4-1에서 우주선 안 소리로 바뀜, 4쪽 바로 가기의 시작 상태를 확인했다.
- 4-2 흐느낌이 울리는 중에 건너뛰면 바로 줄여 꺼진다.
- 5쪽 바로 가기, 5-1 수면실 소리, 5-2 뚜껑과 서리, 5-3 `Fade`의 단계 변화, 암전 뒤 울리는 소리가 하나도 남지 않음을 확인했다.
- 암전 뒤와 1-2 도중의 처음으로(R)에서 소리가 정리되고 1-1부터 다시 시작한다.

확인하지 못한 것:

- 소리를 듣고 장면에 맞는지(Claude는 들을 수 없다). 사용자가 듣고 정한다.
- 3-2 우주선 소리가 울리는 중의 건너뛰기(확인 명령이 늦게 돌아 놓쳤고, 같은 처리를 4-2로 확인했다).
- 암전 중 소리가 줄어드는 도중의 음량 변화(끝 상태만 확인했다), 자동 진행 켬, FMOD Studio가 없는 PC, 빌드.

남은 것: 5-1 금속 발소리(보류), 음량 옵션, 일시정지 소리, 배경음, 옛 오프닝 초인종, Unity 기본 오디오 끄기, 빌드 배포.

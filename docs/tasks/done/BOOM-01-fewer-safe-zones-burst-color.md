# [완료] 안전지대 줄이기와 터지는 색 조정

대상: BOOM-01, BOOM-04 · 영역: [폭발 미로](../specs/maze-boom.md)

> 작업 문서다. 진행 상태와 승인은 여기서 관리하고, 완료된 기능은 영역 스펙에 옮긴다. 지금 게임이 어떻게 동작하는지는 영역 스펙이 기준이다.

사용자가 색 방향("경고는 어둡게, 폭발만 강하게")과 안전지대 자리("층별 2개, 서로 반대에")를 골라 승인했다.

## 무엇을 만드나

### 터지는 칸 무늬 (BOOM-01)

경고는 어둡게 깔고, 터지는 순간만 강하게 보이게 한다.

- 경고는 검은 홍채 위에서 겨우 보이는 어두운 붉은빛으로 시작해, 터질 때가 가까워도 짙은 붉은빛까지만 올라간다. 미로가 갈색으로 넓게 덮이지 않는다.
- 터지는 순간 밝은 주황으로 확 부풀고, 빨강으로 식으며 사라진다.

### 안전지대 (BOOM-04)

안전지대를 12칸에서 6칸으로 줄인다. 층마다 2칸씩 서로 반대편에 있다.

- 바깥 층, 가운데 층, 안쪽 층에 2칸씩이고, 같은 층의 두 칸은 원의 정반대 자리다.
- 층마다 자리를 돌려 놓아 세 층의 안전지대가 한 줄로 늘어서지 않는다.

## 확인 방법

- `MazeTest` 씬을 Play하면 청록색 안전지대가 층마다 2칸씩, 서로 반대편에 6칸 보인다.
- 경고 칸은 어두운 붉은빛이라 미로가 갈색으로 덮이지 않고, 터지는 순간만 밝은 주황으로 확 보였다가 빨강으로 사라진다. Game 뷰 캡처로 바꾸기 전과 비교한다.

## 범위 밖

- 무늬 순서표와 시간은 바꾸지 않는다.
- 격자선, 벽, 시선 색은 바꾸지 않는다.

## 어떻게 만드나

- 색: `MazeBoom.prefab`의 `MazeBoomField`에 `_warnColor`, `_warnEndColor`, `_burstColor`, `_burstEndColor`를 직접 적는다(코드 기본값에 기대지 않는다). 코드 기본값도 같은 값으로 맞춘다.
- 안전지대: 프리팹의 `안전지대 7~12`를 지우고, `안전지대 1~6`의 고리·칸과 위치를 바꾼다. 바깥 층 고리 1의 칸 2와 10, 가운데 층 고리 2의 칸 6과 14, 안쪽 층 고리 4의 칸 0과 8.
- 확인: Unity Pipeline CLI로 Play를 다시 시작해 안전지대 수와 런타임 색을 읽고 Game 뷰를 캡처한다.

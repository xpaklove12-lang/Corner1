# [완료] 사각 미로를 눈 크기와 동공에 맞추기

대상: BOOM-09 · 영역: [폭발 미로](../../specs/maze-boom.md)

> 작업 문서다. 진행 상태와 승인은 여기서 관리하고, 완료된 기능은 영역 스펙에 옮긴다. 지금 게임이 어떻게 동작하는지는 영역 스펙이 기준이다.

사용자가 "눈 크기랑 원 크기가 안 맞는다"고 했다. 바깥은 미로 끝(가로세로 2.85)이 홍채 원판(3.1)보다 작아 빈 띠가 생기고, 가운데는 동공(0.9)이 동공 자리 계단(가로세로 1.05)보다 작아 빈 테가 생겼다. 두 군데 다 맞추기로 해 `[개발중]`으로 시작했다. 처음엔 사각 미로 반지름과 칸 크기 숫자를 홍채에 맞게 바꿨는데, 사용자가 "별도로 두지 말고 홍채 위에 그리면 되잖아"라고 해서 "홍채 원판 전체에 칸을 깔고 가장자리에서 잘라 그리기"로 바꿨다.

## 무엇을 만드나

### 사각 미로 (BOOM-09)

- 사각 미로는 크기를 따로 갖지 않는다. 바깥은 눈 그림의 홍채 원판, 안쪽(동공 자리 기준)은 원형 미로의 안쪽 원에서 바로 읽는다. 눈 크기가 바뀌면 미로도 따라간다.
- 홍채 원판 전체를 칸이 덮는다. 원에 걸친 칸은 홍채 가장자리에서 잘린 회색 격자선으로만 보이고, 들어갈 수 없다(벽, 폭발, 안전지대, 조각, 문 없음). 미로 둘레에 빈 띠가 없다.
- 칸 전체가 홍채 원판 안에 드는 칸만 시선이 다니는 미로 칸이다. 바깥 칸 쪽으로 누르면 튕기고 경계가 잠깐 빛나는 것(BOOM-08)은 그대로다.
- 칸은 화면에서 정확히 6픽셀이라 모든 칸 간격이 같다.
- 폭발 미로가 켜져 있는 동안 동공이 동공 자리 크기에 맞춰져, 동공과 둘레 벽 사이에 빈 테가 없다. 동공은 둘레 벽과 문을 가리지 않는다. 폭발 미로가 꺼지면 원래 크기로 돌아간다.
- 시작 칸은 맨 아래 가운데 칸이다.

## 확인 방법

- `MazeTest`를 Play하면 홍채 원판 전체에 격자가 깔려 있고, 가장자리 칸은 원에 맞게 잘려 보인다. 미로 둘레에 빈 띠가 없다.
- 잘린 가장자리 칸으로는 들어갈 수 없다.
- 동공 하얀 원이 동공 자리를 채우고, 둘레 벽과 문이 가려지지 않는다.

## 범위 밖

- 눈 그림(홍채 원판, 테두리)의 크기와 모양은 바꾸지 않는다. 본 게임 씬의 동공은 바꾸지 않는다.
- 층, 문, 조각, 폭발 동작은 바꾸지 않는다.

## 어떻게 만드나

- `EyeVisual.IrisDiscRadius`(홍채 원판 반지름 = 원형 미로 바깥 반지름 + 여백 절반)를 공개한다. `BoomSquareMaze`의 바깥·안쪽 반지름 Inspector 값을 없애고, 바깥은 `IrisDiscRadius`, 안쪽은 `IrisMaze.InnerRadius`를 쓴다.
- 원에 걸친 칸 판정(`IsDecorCell`)과 선을 원으로 자르기(`ClipSegment`)를 다시 두고, 격자선은 미로 칸과 원에 걸친 칸 경계에 그려 홍채 원판에서 자른다.
- 칸 크기는 0.29333(화면 6픽셀, 1픽셀 = 0.048889)으로 둔다. 시작 칸 (10, 0).
- 동공: `BoomSquareMaze.HoleRadius`(동공 자리 가로세로 반 폭)에서 벽 굵기 절반을 뺀 값을 `Pupil.FitRadiusOverride`로 넣고, 폭발 미로가 꺼지면 비운다.
- 안전지대 6칸은 칸 번호 그대로, 프리팹 위치만 새 칸 크기에 맞춘다.

## 결과

- 바꾼 문서: `docs/specs/maze-boom.md`의 BOOM-09(홍채 위에 바로 그림, 크기는 눈에서 읽음, 잘린 바깥 칸, 동공 맞춤), BOOM-07(잘린 칸 격자), 구성, 코드 단서.
- 코드
  - `EyeVisual.IrisDiscRadius` 공개. `BoomSquareMaze`의 바깥·안쪽 반지름 Inspector 값을 지우고 `IrisDiscRadius`, `IrisMaze.InnerRadius`를 읽는다. `IsDecorCell`, `IsGridCell`, `ClipSegment`를 되살려 격자선을 원에 걸친 칸까지 그리고 홍채 원판에서 자른다(`MazeBoomField.AddGridLine`). `GlowWall`은 바둑판 가장자리 칸의 바깥 경계도 빛낸다.
  - 칸 크기 0.29333(6픽셀), 시작 칸 (10, 0), 안전지대 프리팹 위치를 새 칸 크기에 맞춤.
  - `BoomSquareMaze.HoleRadius`, `Pupil.FitRadiusOverride`, `MazeBoomField.FitPupil`. 폭발 미로가 켜지면 동공을 동공 자리 반 폭에서 반 픽셀 뺀 크기(1.002)에 맞추고, 꺼지면 비운다.
- 확인한 것
  - `unity recompile` 컴파일, 콘솔 오류·경고 없음.
  - Play 값: 바둑판 21×21, 미로 칸 260, 잘린 격자 칸 76, 동공 자리 반 폭 1.027, 동공 목표 반지름 1.002, 시작 칸 (10, 0).
  - Game 창 캡처: 홍채 원판 전체에 격자가 깔리고 가장자리 칸은 원에서 잘려 보인다. 미로 둘레에 빈 띠가 없다. 동공이 동공 자리를 채우고 둘레 벽은 보인다.
  - 시작 칸에서 바둑판 밖(아래)으로 밀면 튕기고 경계선이 빛났다. 층 진행 자동 시험(닫힌 문 안내, 외각 조각과 문과 "폭발이 거세진다.", 내각 조각과 동공 문, 탈출)을 통과했다.
- 확인하지 못한 것: 사람이 직접 보는 느낌. 동공 자리 계단 모서리(대각선 쪽)에는 동공 원과 벽 사이에 작은 틈이 남는다.

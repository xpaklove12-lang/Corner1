# [개발중] 눈 미로 테스트 씬

대상: MTEST-01, MTEST-02, MTEST-03 · 영역: [눈 미로 테스트 씬](../specs/maze-test.md)

> 작업 문서다. 진행 상태와 승인은 여기서 관리하고, 완료된 기능은 영역 스펙에 옮긴다. 지금 게임이 어떻게 동작하는지는 영역 스펙이 기준이다.

## 무엇을 만드나

### 미로만 바로 시작 (MTEST-01)

테스트 씬을 Play하면 필드, 시작 독백, 대화 없이 은재의 눈 미로를 들여다보는 상태로 바로 시작한다.

- 시선은 미로 시작 칸에 놓인다.
- 깜빡임, 미로 회전, 파편과 회상은 본 게임과 같이 동작한다.
- Space를 눌러도 대화로 돌아가지 않고 미로에 머문다.
- 본 게임 씬(`EyeMaze`)은 바꾸지 않는다.

### 테스트 조건 (MTEST-02)

대화를 거치지 않아도 미로 끝까지 갈 수 있게 테스트 조건을 Inspector에서 고른다.

- 층 문 모두 열기: 신뢰나 문 플래그 없이 모든 층 문이 열려 있다. 기본 켬.
- 부담감 끄기: 들여다보는 동안 부담감이 차지 않아 leave 엔딩이 나오지 않는다. 기본 켬.

### 탈출과 다시 하기 (MTEST-03)

동공 한가운데의 가장 반짝이는 파편에 닿으면 엔딩 대사 대신 탈출 안내를 보여 준다.

- "미로를 빠져나왔다. (걸린 시간 n초) R = 다시 하기"를 보여 준다.
- R을 누르면 미로, 파편, 깜빡임 각도를 처음으로 되돌리고 시작 칸에서 다시 들여다본다.
- 걸린 시간은 들여다보기 시작한 때부터 잰다.

## 확인 방법

- 테스트 씬을 Play하면 독백과 필드 없이 눈 미로 화면이 뜨고, 바로 WASD로 시선을 움직일 수 있다.
- 일정 시간마다 눈이 깜빡이고 미로가 돈다.
- 층 문 모두 열기가 켜져 있으면 대화 없이 가장 안쪽 층까지 들어갈 수 있다.
- 부담감 끄기가 켜져 있으면 오래 들여다봐도 부담감 막대가 차지 않는다.
- 동공 한가운데에 닿으면 탈출 안내와 걸린 시간이 보이고, R로 처음부터 다시 할 수 있다.
- 본 게임 씬은 이전과 똑같이 동작한다.

## 범위 밖

- 미로 생성 방식, 깜빡임, 이동 조작 자체를 바꾸지 않는다. 플레이 방식 변경은 이 씬을 만든 뒤 따로 작업한다.
- 새 손님이나 새 미로 데이터를 만들지 않는다. 은재 상담의 미로를 쓴다.
- 빌드 설정의 씬 목록에 테스트 씬을 넣지 않는다.

## 어떻게 만드나

- 씬: `Assets/Scenes/EyeMaze.unity`를 복사해 `Assets/Scenes/MazeTest.unity`를 만들었다. 복사본에서 시작 독백의 Play 시 재생을 끄고, 필드의 `첫 손님 컷신 (Cutscene)`을 꺼서 초인종과 손님 입장이 뒤에서 돌지 않게 했다. UI는 복사된 씬의 것을 그대로 쓰고 코드로 만들지 않는다.
- 시작(MTEST-01): 새 오브젝트 `미로 테스트 (Maze Test)`의 `MazeTestStarter`가 Start에서 `GameFlow.EnterEncounterNow`로 만남 화면에 들어가고, LateUpdate에서 디렉터가 대화 상태면 바로 `ToggleGaze`로 들여다본다. 리셋(R) 뒤에도 같은 경로로 다시 들어간다. Space로 시선을 거두지 않도록 디렉터에 `GazeLocked`를 두었다.
- 테스트 조건(MTEST-02): 미로에 `IrisMaze.OpenAllGates`를 두고 `MazeGate.CanPass`가 이를 먼저 본다. 문 색도 같은 판정을 쓰므로 열린 색으로 그려진다. 부담감은 디렉터의 `BurdenPaused`가 켜져 있으면 차지 않는다. 두 값은 `MazeTestStarter`의 Inspector 값을 매 프레임 적용한다.
- 탈출(MTEST-03): 디렉터에 `CoreTouchOverride`를 두어, 값이 있으면 `TouchCore`가 엔딩 대신 이를 부른다. 테스트 씬은 탈출 안내를 띄우고 디렉터 입력을 멈춘 뒤, R을 직접 받아 `ResetAll`로 되돌린다. 안내 문구는 공용 문구 `msg.maze_test_escape`(두 줄)에 두었다.
- 본 게임 씬에서는 세 값이 모두 꺼져 있거나 비어 있어 동작이 바뀌지 않는다.
- 버린 방법: 씬 YAML에서 필드와 대화 UI를 지운 축소 씬. 참조가 얽혀 깨지기 쉬워 복사본을 그대로 쓰고 필요한 것만 껐다.

# [완료] 씬 문구 번역과 번역 검사

대상: LOC-07, LOC-09, LOC-10 · 영역: [현지화](../specs/localization.md)

> 작업 문서다. 진행 상태와 승인은 여기서 관리하고, 완료된 기능은 영역 스펙에 옮긴다. 지금 게임이 어떻게 동작하는지는 영역 스펙이 기준이다.

## 무엇을 만드나

### 씬 문구 번역 (LOC-07)

씬 인스펙터에 적힌 화면 문구(회상 방 물건 글, NPC 재대화, 앉은 뒤 첫마디, 파편 예비 글)도 언어에 맞게 보여 준다.

### 번역 검사 (LOC-09)

번역 파일을 통째로 바꿔 넣은 뒤, 기획 데이터 검사로 깨진 곳을 찾는다.

### 번역 용어집 (LOC-10)

인물 이름과 고유 용어의 정해진 번역을 용어집 파일에 둔다.

## 확인 방법

- 씬 문구 파일에 영어를 넣고 영어로 바꾸면 회상 방 물건 글이 영어로 나온다.
- 번역에서 `{client}`를 지우면 검사가 오류를 낸다.
- 용어집 파일에 인물 이름과 고유 용어가 있다.

## 범위 밖

- 번역 파일 갱신·가져오기 도구는 만들지 않았다. 번역 파일은 통째로 바꿔 넣는다.

## 어떻게 만드나

- 씬 문구는 새 파일 `Loc/Scene.csv`(공용 문구와 같은 열)에 두고, 인스펙터 칸에는 key만 남긴다. 같은 종류 칸의 같은 글은 key 하나를 같이 쓴다.
  - 고른 이유: 공용 문구와 같은 방식이라 번역 파일을 통째로 바꿔 넣는 작업에 그대로 맞는다.
  - 버린 방법: 컴포넌트마다 고정 ID를 두고 번역하는 방식. 오브젝트를 복제하면 ID가 겹친다.
- 칸 값이 key가 아니면 적힌 글을 그대로 보여 주므로, 옮기기 전에도 게임이 깨지지 않는다.
- 폰트에 없는 글자는 폰트 파일의 글자 표(cmap)를 직접 읽어 찾는다. Unity 동적 폰트의 글자 확인은 글자를 불러오기 전까지 믿을 수 없다.
- 고친 곳: `Strings.Scene`, `LocConfig`, `SceneTextAttribute`, `SceneTexts`, `SceneTextDrawer`, `TranslationCheck`, `FontCmap`, 대상 컴포넌트 4개(`FlashbackProp`, `FieldNPC`, `ClientCase`, `MemoryFragment`).

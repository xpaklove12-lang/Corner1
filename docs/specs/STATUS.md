# 진행 상황

각 스펙 "진행 중"에서 자동으로 만든다. 손으로 고치지 않고 `Tools/check-specs.ps1 -WriteStatus`로 다시 만든다.

## 개발중

| ID | 스펙 | 내용 |
|---|---|---|
| FIELD-01 | [`field.md`](field.md) | 세 인물이 초상화 특징을 살린 전신으로 보인다. |
| FIELD-02 | [`field.md`](field.md) | 손님과 주인공이 이동할 때 방향에 맞는 걷기 동작이 반복된다. |
| FIELD-03 | [`field.md`](field.md) | 컷신에서 앉으면 앉은 자세로 자리에 머문다. |
| FIELD-04 | [`field.md`](field.md) | 컷신에서 퇴장하면 걸어 나가고 퇴장 뒤 보이지 않는다. |
| FIELD-05 | [`field.md`](field.md) | 은재 어머니는 처음 들어와 대화할 때 한 팔을 감싸 쥔 긴장된 자세다. |
| FIELD-06 | [`field.md`](field.md) | 소파에 앉은 손님은 소파 앞부분에 몸 일부가 가려진다. |
| FIELD-07 | [`field.md`](field.md) | 손님별 짧은 보폭의 반복 걷기 GIF를 만든다. |
| FIELD-08 | [`field.md`](field.md) | GIF를 게임 애셋으로 바꿀 때 프레임을 추출하고 중간 동작을 보간해 발 기준점을 맞춘다. |
| FIELD-09 | [`field.md`](field.md) | 주인공도 다른 인물과 어울리는 임시 전신으로 보인다. |
| FIELD-10 | [`field.md`](field.md) | 걷기 주기는 이동 거리에 비례해 진행된다. |
| FIELD-11 | [`field.md`](field.md) | 지금 상호작용 대상인 NPC의 외곽에 테두리가 보인다. |
| FIELD-12 | [`field.md`](field.md) | 대상이 아니거나 대화·컷신 중이면 테두리를 숨긴다. |

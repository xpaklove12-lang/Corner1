# 둘째 상대 고증 노트 (2026-11-20)

> 대상: 치매가 온 할아버지를 돌보는 스물여섯 살 외동 손녀. 할아버지는 어릴 때 손녀를 키워 주었다. 엄마(할아버지의 딸)가 바깥 도움을 막는다.
> 중심 경험: 도와 달라고 하려 했지만 무서움과 가까운 사람의 제지로 하지 못했다. 곁 경험: 숨어서 듣기만 했다. 무게: 중간.
> 출처에서 확인한 것만 적는다. 확인하지 못한 것은 "확인 안 됨"으로 표시한다. 검색 결과 요약과 기사에서 확인했고, 보고서 원문은 읽지 않았다.

## 1. 맞는 것과 어긋나는 것

| 설정 | 판정 | 근거 |
|---|---|---|
| 스물여섯 살 손녀가 조부모를 돌봄 | 맞음 | 2022년 가족돌봄청년(13~34세) 실태조사. 돌봄 대상은 할머니 39.1%, 할아버지 22.0%. 주당 평균 21.6시간(주돌봄자 32.8시간), 평균 46.1개월. 우울감 유병률 약 61%(일반 청년 8.5%). |
| 엄마도 한계에 와 있음 | 맞음 | 2023년 치매역학조사 및 실태조사 인용 기사. 지역사회 치매 환자 가족의 45.8%가 돌봄 부담이 크다고 답했다. |
| 체면과 낙인 때문에 도움 요청이 늦어짐 | 맞음(간접) | 한국어판 치매 공적낙인 척도 연구: 낙인이 조기 진단과 개입을 막는다. 호주 내 한국계 이주민 연구: 낙인이 은폐와 도움 요청 지연으로 이어지고 효 문화가 돌봄 결정에 작용한다. 한국 가족의 은폐 비율을 직접 잰 자료는 확인 안 됨. |
| "요양원 보내면 불효"라는 친척의 말 | 사례만 있음 | 치매 어머니의 요양원 입소를 두고 형제가 다투는 칼럼 사례. 불효 인식을 직접 측정한 조사는 확인 안 됨. |
| 주간보호센터 상담 예약을 엄마가 취소 | 어긋남 | 주야간보호는 장기요양 등급(1~5등급, 인지지원등급)을 받아야 이용할 수 있다. 등급 전에는 성립하기 어렵다. |
| 초기 치매에서 요양원 문제가 나옴 | 어긋남 | 5등급과 인지지원등급은 재가급여만 이용할 수 있다. 초기에 친척이 반대할 대상은 요양원이 아니라 "남의 손"(방문요양, 주간보호)이다. |
| 할아버지가 최근 일을 잊음 | 맞음 | 최근에 배운 정보를 잊는 것이 알츠하이머의 가장 흔한 초기 증상이다. 오래된 기억이 남는다는 설명은 이번 자료에서 확인 안 됨. |
| 할아버지가 손녀를 못 알아보는 장면 | 주의 | 어느 단계에서 생기는지 확인 안 됨(대체로 중후기로 알려져 있다). 드라마가 치매를 자극적인 반전 장치로 써 가족에게 상처가 된다는 지적이 있다. |
| 할아버지를 끝까지 존엄을 가진 사람으로 그림 | 맞음 | 치매 당사자를 경험전문가로 보는 창작 프로젝트. 치매인의 정체성과 존엄은 관계와 상호작용 속에서 지켜진다는 연구. |
| 도움을 청할 곳 | 참고 | 치매안심센터: 60세 이상 무료 선별검사, 가족 상담과 교육, 쉼터(하루 3~7시간), 조호물품. 장기요양 등급은 공단에 신청하면 방문조사를 거쳐 신청일부터 30일 안에 판정한다. |

## 2. 정한 것

- 엄마는 할아버지의 딸이다(사용자 결정, 2026-11-20). 엄마가 도움을 막는 이유는 체면만이 아니라 "우리 아빠를 남의 손에 어떻게 맡겨"라는 사랑과 죄책감이다. 친척의 압박은 외삼촌의 말로 둔다.
- 할아버지가 손녀를 자전거 뒷좌석에 태워 주는 회상은 남긴다(사용자 결정). 주인공 초안 장면 2(아빠가 자전거를 가르쳐 줌)와 모양이 달라 큰 힌트가 되지 않고, 예민한 플레이어가 잡을 수 있는 자리로 둔다. 기억 조각이 장면이 아니라 감각으로 바뀐 것(문답 기록 답 O-1)과 함께 쓴다.

## 3. 이야기 안에서 지킬 것

- 치매를 무섭거나 부담스러운 증상의 볼거리로 쓰지 않는다. 중심은 "가족이 왜 도움을 거부하나"다.
- 할아버지를 짐이나 공포의 대상으로 그리지 않는다.
- 손녀를 못 알아보는 장면을 반전 장치로 쓰지 않는다. 넣을지는 아직 정하지 않았다.

## 4. 확정한 것과 추가 조사 (2026-11-20 오후)

확정(자세한 내용은 `story-protagonist-answers.md` 답 O-2):
- 막힌 도움 요청: 손녀가 몰래 등급을 신청하고, 방문조사 날 엄마가 현관에서 조사원을 돌려보낸다.
- 치매의 단계: 중기. 그래서 1절의 "초기 치매에서 요양원 문제가 나옴: 어긋남"은 풀린다. 중기면 등급이 나올 수 있어 친척이 요양원을 입에 올리는 것이 성립한다.
- 조각의 감각은 폴더폰이 닫히는 소리, 다시 쓰이는 말은 "그 손이 떨리는 걸, 봤던 거죠.", 옛집의 물건은 식탁 위 엄마의 낡은 폴더폰(손녀의 이야기에서는 할아버지의 폴더폰)이다.

중기와 방문조사 추가 조사:

| 설정 | 판정 | 근거 |
|---|---|---|
| 중기에 밤의 배회와 수면 문제가 늘어남 | 맞음 | 중기에 접어들면 판단력 저하, 배회, 망상, 수면장애, 공격성 같은 행동심리증상이 늘어나는 경우가 많다. |
| 해 질 녘부터 밤에 더 불안해하고 헤맴 | 맞음 | 일몰증후군. 해질녘부터 밤 사이 불안, 초조, 혼란, 배회가 심해질 수 있다. |
| 배회를 "어딘가 가려는 행동"으로 그림 | 맞음 | 배회는 목적 없는 행동이 아니라 익숙한 곳을 찾거나 집에 돌아가려는 욕구의 표현으로 이해하자는 관점이 있다. |
| 중기에 가족을 못 알아봄 | 확인 안 됨 | 이번 자료에는 어느 단계에서 생기는지 설명이 없다. |
| 좋은 날과 나쁜 날의 기복 | 확인 안 됨 | 직접 다룬 자료를 찾지 못했다. |
| 방문조사 날 어르신이 평소보다 멀쩡하게 행동 | 사례 있음(블로그) | 긴장해서 평소보다 잘 움직이거나 어려움을 줄여 말해 등급 외 판정을 받는 사례가 있다고 하며, 보호자가 평소 상태를 설명하라고 권한다. 공식 통계는 확인 안 됨. |
| 조사는 조사 당일만 보지 않음 | 맞음 | 공단 직원이 집을 방문해 조사표로 조사하고, 인지와 행동 변화는 최근 한 달의 증상을 묻는다. 보호자의 진술이 중요하다. 일정은 공단 직원과 협의해 잡는다. |
| 밤에 나간 할아버지를 112 신고로 찾음 | 맞음 | 실종 신고 뒤 경찰이 CCTV로 동선을 추적하고 목격 제보로 찾는 사례가 많다. 평균 발견 시간 660분(배회감지기 착용 시 55분)은 단일 출처라 수치는 쓰지 않는다. |
| 공격성 | 주의 | 중기에 공격성이 늘 수 있다는 자료가 있지만, 주인공의 아빠와 겹쳐 보이므로 이 이야기에서는 쓰지 않는다. |

남은 것:
- 손녀를 못 알아보는 장면은 근거를 확인하지 못했다. 트리트먼트에서는 "못 알아본다"가 아니라 "다른 때의 사람으로 부른다"로 쓰고, 플롯 단계 전에 다시 조사한다.
